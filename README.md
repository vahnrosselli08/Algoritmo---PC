# Algoritmos e Pensamento Computacional
## Aula 2 - Introdução à Linguagem C
Enunciados dos Exercícios da Aula 2:
Em uma oficina mecânica, muitas peças possuem formato circular, como rolamento,
engrenagens e polias. Para calcular a quantidade de material necessária para fabricar uma
proteção ao redor de uma peça circular, o técnico precisa conhecer o comprimento da
borda dessa peça, ou seja, o perímetro da circunferência.
1- Desenvolva um programa em C que leia o valor do raio de uma peça circular (em centímetros),
calcule o perímetro da circunferência usando a fórmula: perímetro = 2 * pi * raio e exiba o resultado
com duas casas decimais.

Uma empresa de paisagismo está elaborando o projeto de um jardim retangular. Para instalar uma cerca ao redor do jardim, é necessário conhecer o seu perímetro, e para calcular a quantidade de grama que será utilizada, é preciso determinar a área do terreno.
2-Desenvolva um programa em C que leia o comprimento e a largura de um jardim retangular(em metros); calcule o perímetro do jardim utilizando a fórmula: perímetro=2*(comprimento + largura)e a área do jardim utilizando a fórmula: área=comprimento*largura. Ao final exiba os resultados com duas casas decimais
